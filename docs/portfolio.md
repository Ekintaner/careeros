## English CV project entry

**CareerOS — Full-stack job-search workspace**

Next.js · TypeScript · ASP.NET Core · EF Core · PostgreSQL · Redis · Docker · GitHub Actions

- Developed a self-hostable workspace for applications, private PDF resumes, interview planning, skill evidence and career analytics.
- Implemented owner-scoped data access, rotating cookie sessions, CSRF protection and concurrency-safe updates across a layered .NET API.
- Added deterministic skill matching and optional consent-based local Ollama assistance, disabled by default with no paid API dependency.
- Validated behavior with unit/frontend tests, real PostgreSQL integration tests and a synthetic paired database/document restore drill; documented reproducible local setup and limitations.

## English LinkedIn project description

CareerOS brings a job search into one private workspace: opportunities, application history, resumes, skill gaps, interviews and follow-ups. It combines a Next.js/TypeScript interface with a layered ASP.NET Core API, PostgreSQL and Redis. The project emphasizes data ownership, explained deterministic matching, reproducible tests and paired database/document recovery. Optional local AI requires consent and stays disabled by default. The release is designed for local self-hosting without mandatory paid services; it is not presented as a publicly deployed service. Source and verification: https://github.com/Ekintaner/careeros
